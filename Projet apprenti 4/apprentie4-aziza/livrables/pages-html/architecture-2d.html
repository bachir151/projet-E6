Le fil de la soutenance

Les 5 règles du projet

  1. Avoir un fichier ne prouve pas qu'il est le bon : l'empreinte SHA-256 est comparée au catalogue.
  2. Le réseau n'est pas de confiance (4G, Internet) : seul le catalogue signé fait foi.
  3. Un PC éteint ne peut rien affirmer : la borne lit le dernier rapport. Serveur muet = « vérification impossible », jamais « à jour ».
  4. Sur le terrain, le réseau manque : seuls les fichiers modifiés voyagent, BITS reprend après une coupure.
  5. Chaque version a une valeur : rien n'est écrasé, l'historique sert d'archive.
