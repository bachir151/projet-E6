Le fil de la soutenance

Les 4 règles du projet

  1. Windows sait qu'il s'est mal arrêté, pas pourquoi : le boîtier témoin voit ce que Windows ne peut pas écrire.
  2. Le récit survit à la coupure : horloge, carte mémoire et réserve d'énergie dans le boîtier.
  3. Cause probable ou « non concluant » : si les sources ne sont pas d'accord, le programme le dit.
  4. Lecture seule : le système explique, il ne répare rien sur le poste.
