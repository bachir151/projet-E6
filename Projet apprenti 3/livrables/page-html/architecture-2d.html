Le fil de la soutenance

Les 5 règles du projet

  1. Inactif ne veut pas dire absent : le radar voit la respiration, le clavier non.
  2. Le verrou reste local : il ne dépend ni du serveur ni du réseau. Une panne ne laisse jamais le poste ouvert.
  3. Chaque message est signé (HMAC + compteur + défi) : un faux boîtier ou un message rejoué est refusé.
  4. Une connexion au leurre n'est pas une intrusion : c'est un signal à qualifier.
  5. L'absence n'est pas une identité : la supervision n'attribue jamais un événement réseau à une personne absente.
